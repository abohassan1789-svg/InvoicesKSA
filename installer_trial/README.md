# PHASEINV2 — Trial installer (embedded PostgreSQL)

A **brand-new, self-contained** trial build. One installer file the customer
runs directly — nothing else to install (no Python, **no PostgreSQL**).

## What makes it a trial

Enforced by the application itself (`app/security/trial_guard.py`):

- Expires after **7 days**, or
- after **40 launches**,

whichever comes first. State is kept in a signed file
(`%ProgramData%\PHASEINV2\.license.dat`) **and** mirrored in the registry
(`HKCU\Software\PHASEINV2`); the two are reconciled to the most conservative
value, so deleting one does not reset the trial, and a backwards clock is
treated as tampering. A gentle reminder appears when ≤ 2 days or ≤ 5 launches
remain.

## Embedded PostgreSQL (no install at the customer)

`app/services/embedded_postgres.py` bundles a **portable** PostgreSQL
(`bin`/`lib`/`share`) inside the frozen app under `_internal\pgsql`. On launch it:

1. runs `initdb` once into `%ProgramData%\PHASEINV2_Trial\pgdata` (trust auth, UTF-8,
   `C` locale),
2. starts `postgres` on **127.0.0.1:55432** (loopback only — never clashes with
   a "real" PostgreSQL on 5432),
3. creates the `InvPhase2` database if missing,
4. writes the encrypted connection profile so the rest of the app is pointed at
   the embedded server with no code changes,
5. stops the server cleanly on exit.

The app then provisions its full schema automatically on first launch (the same
idempotent `ensure_full_schema` path the production build uses).

The VC++ runtime DLLs (`vcruntime140*.dll`, `msvcp140.dll`) are copied next to
`postgres.exe` so it runs on a machine without the Microsoft Visual C++
Redistributable.

## Build it

```powershell
.\installer_trial\build.ps1
```

Output: **`D:\PHASEINV2\dist\PHASEINV2_TRIAL_Setup.exe`** (single file to hand to
the customer). Prints size + SHA-256 at the end.

Useful switches:

- `-RefreshPg` — re-copy the portable PostgreSQL payload (use after a PostgreSQL
  upgrade on the build machine).
- `-PgSource 'C:\Program Files\PostgreSQL\18'` — pick the source PostgreSQL.
- `-PythonExe` / `-InnoCompiler` — override tool locations.

> PowerShell 5.1: never pipe the build through `2>&1` — PyInstaller logs INFO to
> stderr and the redirect makes a succeeding build look failed.

## What gets installed on the customer machine

- `C:\Program Files\PHASEINV2 Trial\` — the frozen app + embedded PostgreSQL.
- `C:\ProgramData\PHASEINV2_Trial\` — `pgdata` (the embedded cluster),
  `connection.json`, `logs`, `Backups`, and the trial license file. All
  user-writable so the app and its database run **without administrator rights**.
  This folder is **isolated** from a production `PHASEINV2` install, so the trial
  can sit on the same machine without disturbing it.

Uninstalling stops the embedded server and removes `pgdata`, the connection
profile, and the trial state (backups are kept).
