# شركة «زيادة البركة التجارية» — بائع النموذج الثاني والعشرون

`barakah_company.sql` يضيف الشركة اللي في ملف PDF النموذج ٢٢ لقائمة الشركات بختمها:

- الاسم: شركة زيادة البركة التجارية
- السجل التجاري: 7009631370 — الرقم الضريبي: 311369317100003
- العنوان: جدة - العزيزية - البلدية - 23334
- الختم: `stamp.png` (متاخد من الـ PDF نفسه)

ينفع يتشغل أكتر من مرة: الشركة بتتضاف بس لو مش موجودة (بالرقم الضريبي أو السجل)،
ولو موجودة من غير ختم بياخد الختم.

التشغيل على داتابيس البرنامج:

```
psql -h localhost -U postgres -d <اسم الداتابيس> -v ON_ERROR_STOP=1 -f tools/barakah_company/barakah_company.sql
```

`gen_sql.py` بيولّد الملف من البيانات اللي فوق و`stamp.png`.
