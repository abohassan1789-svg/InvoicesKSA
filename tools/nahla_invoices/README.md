# فواتير «نهلة الخليج» — مؤسسة صرح الرفاع التجارية

`nahla_invoices.sql` يضيف 7 فواتير مبيعات (مسودات) بأرقام وتواريخ ومبالغ شيت الإكسل
(4487–4585، إجمالي 102,000 قبل الضريبة + 15,300 ضريبة = 117,300)، وأصنافها أصناف حرة
من عرض أسعار «نواقص».

- يضيف شركة «نهلة الخليج» والعميل لو مش موجودين (البحث بالرقم الضريبي).
- كله في transaction واحدة، ولو أي رقم من أرقام الفواتير موجود لنفس الشركة بيقف من غير ما يغيّر حاجة.
- بيانات ZATCA (UUID / XML / QR) ما بتتكتبش؛ البرنامج بيعملها لما الفاتورة تتحفظ من الشاشة.

التشغيل على داتابيس البرنامج:

```
psql -h localhost -U postgres -d <اسم الداتابيس> -v ON_ERROR_STOP=1 -f tools/nahla_invoices/nahla_invoices.sql
```

`gen_sql.py` بيولّد الملف من `alloc.json` (أصناف كل فاتورة) وبيتأكد إن إجماليات كل فاتورة مطابقة للإكسل.
